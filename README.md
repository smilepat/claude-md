# GitHub 템플릿 레포지토리로 `claude.md` 활용하기 (추천 방법 1)

이 레포지토리(`claude-md`)는 멀티 PC 환경에서 여러 앱을 개발할 때, 일관된 AI 행동 지침서(`claude.md`)를 즉시 불러오기 위한 템플릿 저장소입니다.

## 🚀 1. 이 레포지토리를 템플릿으로 설정하기 (최초 1회)
이미 설정되어 있을 수도 있지만, 다음 방법으로 이 레포지토리를 언제든 재사용 가능한 템플릿으로 만들 수 있습니다.

1. 현재 레포지토리의 상단 메뉴 중 **[Settings (설정)]**을 클릭합니다.
2. 좌측 메뉴의 **General** 탭에서 중간쯤 위치한 **[Template repository]** 네모 박스를 찾아 체크(✅)합니다.
3. 이제 이 저장소는 단순 코드가 저장되는 곳이 아니라, 새 앱을 찍어내는 '거푸집(Template)'이 되었습니다!

## 🔥 2. 새로운 앱 시작할 때 `claude.md` 쏙 빼오기
새로운 코딩 프로젝트를 시작하려 할 때, 백지상태가 아니라 AI 매뉴얼이 탑재된 채로 시작하는 방법입니다.

1. GitHub 우측 상단 **[+ ▼]** 버튼을 누르고 **[New repository]**를 클릭합니다.
2. Repository name을 입력하는 곳 바로 위에 **[Repository template]** 이라는 선택 칸(드롭다운)이 보입니다.
3. 해당 드롭다운을 열어 방금 템플릿으로 설정한 `claude-md` (또는 `smilepat/claude-md`)를 선택합니다.
4. 평소처럼 Repository 이름을 적고 **[Create repository]**를 누릅니다.

**🎉 완료!**
이제 새로 만든 저장소를 내 컴퓨터에 클론(`git clone`) 해보면, 번거롭게 복사/붙여넣기를 하지 않아도 이미 폴더 안에 `claude.md` 파일이 예쁘게 들어있을 것입니다. VS Code를 켜자마자 AI가 이 지침을 따르며 코딩을 도와줍니다!
